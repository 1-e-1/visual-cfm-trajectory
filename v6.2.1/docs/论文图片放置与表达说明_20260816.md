# 论文图片放置与表达说明

## 1 排版原则

论文正式图按“任务问题 -> 方法结构 -> 关键机制 -> 总体性能 -> 机制分析 -> 应用验证”组织，
不再沿用绘图脚本的历史编号。正式图片位于 `paper_figures/manuscript/`，PNG 用于 Markdown
预览，PDF 或 SVG 用于期刊排版。表 1 保留，因为它定义输入输出张量；原表 2--7 与统计图信息重复，
已由图 6--14 替代。

## 3 原 Fig.06 与 Fig.12 的明确解释

源 `Fig.06` 现作为正文图 7，只用于回答“49 个未见布局上的轨迹可行性是否对 CFM
采样种子稳定，以及失败原因是什么”。它应放在 6.2，不用于说明模型结构，也不用于与其他规划器比较。

源 `Fig.12` 现作为正文图 6，只用于回答“本文方法与 RRT-Connect、STOMP 相比，在可行率、
规划时间和低冲击指标上分别处于什么位置”。它应放在 6.1。图的正确结论是：经典规划器更可行、
更快；本文方法的优势是共同成功任务上的加速度和 jerk 更低。该图用于呈现明确的性能取舍，
不能写成本文方法全面优于经典规划器。

## 4 不进入正式论文的图

源 `Fig.13 carrying_stability` 暂不编号、不插入正文。B 实验的名义原生接触任务未通过有效性
审计，缺少 100 次有效随机 rollout，因此该占位图不能作为实验结果。正文 6.8 只保留固定任务
应用展示，并明确其统计边界。

## 5 图注和正文写法

1. 图注解释“画了什么”和统计口径，结论放在正文，避免图注重复整段结果。
2. 成功率图必须标出样本量和 Wilson 95% CI；连续差异必须说明是共同成功任务上的配对结果。
3. 多面板图在正文中按 `(a)--(d)` 顺序解释，不能只引用整张图而不说明读图路径。
4. 视觉结果、轨迹可行性和完整接触任务成功必须分开表述，不使用单一“成功率”混合三个层级。
5. 方法示意图采用 PDF/SVG，仿真关键帧采用 PNG；禁止拉伸图片改变宽高比。
