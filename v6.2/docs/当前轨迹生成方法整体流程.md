# 当前完整研究方法技术路线

## 1. 研究目标与方法边界

本研究面向航天员辅助外肢体机械臂，目标是在给定辅助机械臂当前关节角和目标 TCP 位置的条件下，利用多相机视觉生成多条候选关节轨迹，并通过几何、运动学、动力学与 PhysX 验证，得到尽可能安全、平滑、低冲击的执行轨迹。

当前完整方法包括：

1. 五相机 RGB-D-semantic 环境感知；
2. Visual Conditional Flow Matching（Visual CFM）多候选轨迹生成；
3. 视觉点云环境避障筛选；
4. 基于已知机械臂 kinematics 与 capsule 几何的自碰撞检查；
5. 保持目标 TCP 位置的安全终态投影；
6. full64 PPO 中段自碰撞细化实验分支；
7. adaptive exact safety gate 与动力学复核；
8. 50 Hz 关节位置控制与离线 PhysX replay。

当前方法不是严格意义上的端到端纯视觉系统。环境障碍物来自视觉，但自碰撞检查使用辅助机械臂自身关节角、FK 和 capsule 几何；目标位置由任务系统直接给出，不由视觉网络检测；H1 本体状态不输入轨迹生成模型。

## 2. 总体技术路线

```text
离线训练：
随机 q_start/q_goal + Isaac Sim 场景随机化
  -> 五相机 RGB-D-semantic + 视觉点云 + 专家轨迹
  -> privileged obstacle encoder 教师表示
  -> 五相机视觉 latent distillation
  -> Visual CFM v5 微调

随机关节构型 + exact capsule 标签
  -> Neural C-SDF

安全轨迹 + 局部中段碰撞扰动
  -> 4096条 PPO 训练任务
  -> full64 PPO v3

推理：
五相机观测 + q_start + p_goal_in_foot_0
  -> 视觉编码 z_visual
  -> 32步 Heun ODE 生成 K=64 条 64x6 候选及 duration
  -> position-only terminal IK + 64到1024点前置插值 + 未截断时间缩放
  -> 视觉环境间距 + 自碰撞 + 动力学多候选筛选
  -> 选中 64x6 轨迹
  -> 安全终态投影 + 强制重算时间缩放
  -> full64 PPO 1024点 proposal + 强制重算时间缩放
  -> adaptive exact safety gate
  -> 最终 1024x6 轨迹 + duration + success flag
  -> 50 Hz 时间插值执行
  -> 固定子集 PhysX 离线验证
```

## 3. 数据、坐标系与符号

### 3.1 核心张量

| 名称 | Shape | 含义 |
|---|---:|---|
| `q_start` | `[B,6]` | 当前六关节角 |
| `p_goal` | `[B,3]` | 目标 TCP 在对应辅助臂 `foot_0` 坐标系中的位置 |
| `q_goal` | `[B,6]` | 数据生成阶段的目标关节构型，仅作专家标签和审计信息 |
| `q_candidates` | `[B,64,64,6]` | 每个任务64条候选，每条64点 |
| `q_selected` | `[B,64,6]` | 多候选筛选后的轨迹 |
| `q_final` | `[B,1024,6]` | 最终关节位置轨迹 |
| `duration_raw` | `[B]` | 冻结 Duration Head 的原始预测，范围 `0.8-5.0 s` |
| `duration` | `[B]` | 1024点轨迹重算后的执行时长，单位 s；不硬截断，当前有效性上限30 s |

最后一维 `6` 始终表示 `[joint1,...,joint6]` 六个关节角，不表示位置、速度、加速度等六类信息。

### 3.2 目标与点云坐标系

目标位置定义为：

```text
p_goal = 目标 TCP 在当前辅助机械臂 foot_0 坐标系下的三维坐标
```

它不是世界坐标，也不是当前 TCP 到目标的相对位移。左、右辅助臂分别使用各自的 `foot_0` 坐标系。

Depth 通过相机内参反投影，再利用相机外参变换到对应辅助臂 `foot_0` 坐标系。五视角融合后输出：

```text
scene_points     [B,2048,3]
scene_point_mask [B,2048]
```

Semantic 用于移除当前活动辅助臂自身像素；H1 本体、另一条辅助臂和环境物体保留为需要避让的视觉几何。

### 3.3 周期关节

六个关节没有物理角度限位，但训练和推理统一映射到：

```text
q in [-pi,pi)^6
```

插值前进行 periodic unwrap，输出前重新 wrap，避免在 `-pi/pi` 边界走长路径。

## 4. 离线训练路线

### Step T1：随机任务与五相机数据生成

**输入**

| 输入 | Shape | 来源 |
|---|---:|---|
| 随机 `q_start` | `[6]` | 每个关节在 `[-pi,pi)` 独立均匀采样 |
| 随机 `q_goal` | `[6]` | 每个关节在 `[-pi,pi)` 独立均匀采样 |
| 随机场景 | 场景状态 | 静态、动态及小型漂浮障碍物随机化 |
| 五相机 | 5 views | wrist、cube、chest、abdomen、head |

**处理**

1. 通过 FK 将 `q_goal` 转换为 `p_goal_in_foot_0[3]`；
2. 过滤起点、终点或环境不可行任务；
3. 生成直接路径和带 waypoint 的周期 minimum-jerk 专家候选；
4. 选择满足环境、自碰撞和动力学约束的专家轨迹；
5. 采集五相机 RGB、Depth、Semantic 并重建点云。

**输出**

| 输出 | Shape | 用途 |
|---|---:|---|
| `condition=[q_start,p_goal]` | `[9]` | 模型条件输入 |
| `rgb` | `[5,2,128,128,3]` | 视觉输入 |
| `depth` | `[5,2,128,128,1]` | 视觉输入和点云重建 |
| `semantic` | `[5,2,128,128,1]` | 视觉输入和像素过滤 |
| `scene_points` | `[2048,3]` | 候选环境间距检查 |
| `scene_point_mask` | `[2048]` | 点云有效位掩码 |
| `obstacle_tokens` | `[5,14]` | 训练阶段 privileged teacher 与碰撞损失 |
| 专家轨迹 `q` | `[64,6]` | Visual CFM 标签 |
| `duration` | 标量 | duration head 标签 |
| `q_goal` | `[6]` | 仅用于标签生成和审计 |

**目的**

建立从多视角视觉、当前关节角和目标位置到安全专家轨迹的监督数据。

**边界**

关节角先均匀采样，再经过可行性拒绝过滤，因此最终训练集并非严格均匀分布。当前数据虽然有2帧接口，但生成脚本将单次静态采集复制为2帧，尚不能证明模型能从时间序列估计动态障碍物速度。

### Step T2：privileged obstacle encoder 训练

**输入**

```text
obstacle_tokens [B,5,14]
obstacle_mask   [B,5]
```

**处理**

使用3层、4个 attention heads、hidden dimension 128的 Transformer encoder 编码结构化障碍物信息。

**输出**

```text
z_teacher [B,128]
```

**目的**

学习稳定的环境教师表示，为视觉编码器提供蒸馏目标。Privileged obstacle token 不进入最终视觉推理输入。

### Step T3：五相机视觉 latent distillation

**输入**

```text
RGB      [B,5,2,128,128,3]
Depth    [B,5,2,128,128,1]
Semantic [B,5,2,128,128,1]
z_teacher[B,128]
```

每帧拼接 `RGB(3)+Depth(1)+Semantic(1)` 共5通道，再将 `5 views x 2 frames` 融合为50通道图像。视觉 backbone 的卷积通道为32、64、128、192，随后 global average pooling 和 linear projection。

**输出**

```text
z_visual [B,128]
```

**Loss**

```text
L_distill = MSE(z_visual,z_teacher)
```

**目的**

让视觉编码器近似 privileged teacher 的环境表示，使推理阶段不依赖障碍物真值 token。

### Step T4：Visual CFM v5 微调

**输入**

| 输入 | Shape |
|---|---:|
| 周期噪声轨迹 `x_0` | `[B,64,6]`，归一化至 `[-1,1)` |
| 专家轨迹 `x_1` | `[B,64,6]` |
| Flow time `t` | `[B]` |
| `condition=[q_start,p_goal]` | `[B,9]` |
| `z_visual` | `[B,128]` |

周期 Flow Matching 插值为：

```text
Delta = wrap(x_1-x_0)
x_t = wrap(x_0+t*Delta)
v_target = Delta
```

`q_start` 在模型内部编码为 `sin/cos`，条件编码维数为 `12+3=15`。轨迹 Transformer 使用 hidden dimension 192、4层、4个 attention heads，time embedding dimension 128。

**输出**

| 输出 | Shape | 含义 |
|---|---:|---|
| `v_theta(x_t,t,c)` | `[B,64,6]` | 条件速度场 |
| `duration_pred` | `[B]` | 冻结 Duration Head 输出，映射到 `0.8-5.0 s`；仅作为后续时间缩放的下界建议值 |

**Loss**

```text
L = 1.00 L_flow + 10.0 L_start + 25.0 L_final_tcp
  + 0.10 L_velocity + 0.10 L_acceleration + 0.08 L_jerk
  + 1.00 L_duration + 2.00 L_environment_collision
  + 4.00 L_self_collision
```

训练中的环境碰撞损失使用 privileged obstacle tokens，模型条件分支使用视觉输入。v4 不重新训练 CFM；数据集和 Duration Head 均通过 SHA-256 manifest 冻结。

**目的**

学习视觉条件下的多模态轨迹分布，而不是只回归一条平均轨迹；同时约束起点、TCP终点、平滑性、环境间距和自碰撞间距。

### Step T5：Neural C-SDF 训练

**输入**

```text
q [N,6], q_i in [-pi,pi)
```

构型来自 Sobol sampling、独立均匀采样及自碰撞边界附近扩增，共65,536条；标签由已知 FK 与非相邻 link capsule 几何计算。

**模型输入与输出**

```text
input:  [sin(q),cos(q)] [N,12]
output: predicted_self_clearance [N]
        self_collision_logit     [N]
```

**目的**

提供可微分的 configuration-space self-clearance，用于安全终态搜索和 PPO 安全梯度。最终判定仍由 exact capsule oracle 完成。

### Step T6：中段碰撞任务生成

**输入**

```text
q_safe_reference [N,64,6]
duration         [N]
```

**处理**

在轨迹内部施加 compact-support cosine bump，随机选择中心、半径、幅度和关节方向；保持首尾不变，只保留端点安全且中段 exact-unsafe 的轨迹。

**输出**

```text
训练集 q_collision [4096,64,6]
测试集 q_collision [512,64,6]
q_safe_reference  [N,64,6]  # 仅用于数据生成和可行性审计
duration          [N]
```

**目的**

构造首尾安全但中段自碰撞的专门任务。训练和测试使用不同源数据 split。

### Step T7：full64 PPO v3 训练

**输入**

```text
q_collision [B,64,6]
```

64个轨迹点全部作为控制点，首尾固定，62个内部点可修改。Cubic spline 将控制点展开为1024点轨迹。

**Observation**

| 组成 | 维数 |
|---|---:|
| 当前64控制点 `sin/cos` | `64x12=768` |
| 原始64控制点 `sin/cos` | `64x12=768` |
| 64个控制点 C-SDF clearance | `64` |
| 62个内部点 residual | `62x6=372` |
| 最小/平均 clearance、违规比例、step进度 | `4` |
| 合计 | `1976` |

**Action**

```text
action [B,62]
```

每个 action 是标量门控系数，控制对应内部点沿 C-SDF clearance 梯度修正。单步最大修正 `0.04 rad`，共8步，累计 residual 限制 `0.45 rad`。

**Reward**

```text
r_t = gamma*Phi(s_next)-Phi(s)
      - action penalty
      - adjacent action oscillation penalty
      + terminal success reward
```

势函数包含最小 clearance、碰撞点比例、轨迹偏移、acceleration proxy、Jerk proxy 和相邻 residual oscillation。

**输出**

```text
q_ppo_proposal [B,1024,6]
```

碰撞检查使用1024点；平滑 reward 在同一 spline 的256点参考网格计算，避免 float32 高阶差分噪声随采样密度放大。

**目的**

不修改起点和终点，尝试修复中段自碰撞并降低加速度、Jerk和相邻点振荡。

## 5. 推理与安全复筛路线

### Step I1：读取任务输入

**输入**

```text
q_start [B,6]
p_goal_in_foot_0 [B,3]
RGB      [B,5,2,128,128,3]
Depth    [B,5,2,128,128,1]
Semantic [B,5,2,128,128,1]
```

**输出**

```text
condition [B,9]
```

**目的**

定义轨迹生成任务和视觉环境条件。

**不读取**

H1关节状态、H1基座状态、USD障碍物位姿真值和专家 `q_goal[6]`。

### Step I2：视觉编码与点云重建

**视觉编码分支**

```text
input:  RGB + Depth + Semantic
output: z_visual [B,128]
purpose: 为Visual CFM提供紧凑环境条件
```

**点云分支**

```text
input:  Depth + Semantic + camera intrinsics/extrinsics
output: scene_points [B,2048,3] + scene_point_mask [B,2048]
purpose: 为候选轨迹提供显式环境clearance
```

固定测试使用由同一组 Depth 预先重建并缓存的点云，不读取 USD obstacle truth。

### Step I3：生成64条Visual CFM候选

**输入**

```text
condition [B,9]
z_visual [B,128]
64组周期均匀噪声 [B,64,64,6]
```

每条候选使用32步 Heun ODE，并在每步重新固定第一帧为 `q_start`。

**输出**

```text
q_raw_candidates        [B,64,64,6]
duration_raw_candidates [B,64]
```

**目的**

从不同噪声初值生成多样候选。32是 ODE 数值积分次数，64是轨迹点数，两者不是同一概念。

### Step I4：terminal IK、前置插值与未截断时间缩放

**输入**

```text
q_raw_candidates [B,64,64,6]
duration_raw     [B,64]
p_goal           [B,3]
```

**处理**

1. 对候选末端执行 position-only IK，不约束姿态；
2. 将终端关节修正平滑分布到64点轨迹；
3. 在计算时间尺度之前，强制用 periodic-aware clamped cubic spline 将每条 `64x6` 轨迹插值为 `1024x6`；
4. 在1024点样条上计算对归一化路径参数的一至三阶导数；
5. 分别由 velocity、acceleration、Jerk soft limits 反算所需最短时长；
6. `duration=max(duration_raw,duration_required,0.8)`，不再执行 `clip(...,5.0)`；
7. `duration>5.0 s` 仅记录 `duration_exceeds_nominal_max=true`，不判失败；
8. duration 非有限值或 `duration>30.0 s` 时记录 `duration_valid=false`，数值仍不截断。

**输出**

```text
q_processed_candidates [B,64,64,6]
q_timed_dense_candidates [B,64,1024,6]
duration_processed     [B,64]
duration_exceeds_nominal_max [B,64]
duration_valid         [B,64]
```

**目的**

降低原始候选的 TCP 终点误差，并避免先按64点计算时长、后插值到1024点所造成的导数低估。5 s 是名义阈值，30 s 是当前输出有效性上限。

### Step I5：多约束候选筛选

**输入**

```text
q_processed_candidates [B,64,64,6]
q_timed_dense_candidates [B,64,1024,6]
duration_processed     [B,64]
scene_points           [B,2048,3]
p_goal                 [B,3]
```

**候选指标**

```text
terminal_error_m
visual_environment_clearance_m
capsule_self_clearance_m
velocity_rms_rad_s
acceleration_rms_rad_s2
jerk_rms_rad_s3
dynamics_ok
duration_ok
```

**成功判据**

```text
terminal_error <= 0.030 m
environment_clearance >= 0.010 m
self_clearance >= 0.010 m
velocity/acceleration/Jerk <= planning soft limits
duration为有限值且不超过30.0 s
```

成功候选按以下分数选择：

```text
score = terminal_error
      + 0.002*acceleration_rms
      + 0.0002*jerk_rms
```

若没有成功候选，返回终点误差最小的失败候选并保留失败标志。

**输出**

```text
q_selected        [B,64,6]
q_selected_dense  [B,1024,6]
duration_selected [B]
selection_report
```

**目的**

利用多候选性避开单一路径失败，并在成功候选中偏向低冲击路径。

### Step I6：安全终态投影

**输入**

```text
q_selected [B,64,6]
p_goal [B,3]
Neural C-SDF + exact capsule oracle
```

**处理**

1. exact 检查起点和终点；
2. 起点不安全时报告初态不可行，不修改实际起点；
3. 终点不安全时用 C-SDF 梯度搜索新终态；
4. 首轮32 restarts、300 iterations，失败后64 restarts、500 iterations；
5. 同时满足 TCP误差 `<=0.003 m` 与 exact self-clearance `>=0.010 m`；
6. 用 `10u^3-15u^4+6u^5` minimum-jerk phase 将修正分布到64点轨迹。

**输出**

```text
q_projected [B,64,6]
terminal_projection_found [B]
terminal_projection_report
```

**Step I6-R：强制重算时间缩放**

终态投影改变了64点路径几何后，立即重新执行“64到1024点插值 -> 未截断时间缩放”，输出：

```text
q_projection_dense [B,1024,6]
duration_projection [B]
duration_projection_valid [B]
```

**目的**

解决 terminal IK 终态可能自碰撞的问题，同时保持目标 TCP 位置。v4固定206条任务中59条需要修正，59条均成功；修正后的 duration 不复用修正前数值。

### Step I7：1024点基准轨迹与PPO proposal

**输入**

```text
q_projected [B,64,6]
```

**输入A**

```text
q_projection_dense [B,1024,6]
duration_projection [B]
```

该分支由 Step I6-R 得到，作为稳定基准轨迹。

**输出B**

```text
PPO observation [B,1976]
  -> q_ppo_proposal [B,1024,6]
```

**Step I7-R：强制重算时间缩放**

PPO 改变轨迹几何后，以 `duration_projection` 为预测下界重新执行未截断时间缩放：

```text
q_ppo_proposal_retimed [B,1024,6]
duration_ppo [B]
duration_ppo_valid [B]
```

**目的**

基准分支提供可回退轨迹；PPO分支尝试增加中段 self-clearance。

### Step I8：adaptive exact safety gate

**输入**

```text
q_projection_dense [B,1024,6]
duration_projection [B]
q_ppo_proposal_retimed [B,1024,6]
duration_ppo [B]
exact capsule oracle
```

每个相邻区间按最大关节变化 `0.025 rad` 自适应加密，靠近10 mm边界时额外细分。PPO proposal 只有在以下条件下被接受：

```text
proposal exact-safe且duration_ppo_valid
且 projection不安全
或 proposal最小clearance比projection至少高0.001 m
```

**输出**

```text
q_after_gate [B,1024,6]
duration_after_gate [B]
policy_proposal_accepted [B]
adaptive_self_collision_report
```

**目的**

阻止 C-SDF 近似误差或 PPO 过度修正进入执行轨迹，并在无改善时回退。安全门选择哪条路径，就同时选择该分支重算后的 duration，禁止路径与时长错配。

v4的206条测试中 projection safe为206/206，PPO proposal safe为129/206，PPO接受数为0/206。因此当前最终性能仍不是 PPO 带来的。

### Step I9：最终环境与动力学复核

**输入**

```text
q_after_gate [B,1024,6]
duration [B]
scene_points [B,2048,3]
p_goal [B,3]
```

**处理**

1. 计算 TCP 终点误差；
2. 使用1024点 link capsules 与视觉点云计算环境 clearance；
3. 使用 adaptive exact oracle 计算 self-clearance；
4. 在1024点时间网格计算动力学指标，使用 `1e-6` 相对数值容差处理浮点边界；
5. 汇总所有成功条件。

**输出**

```text
q_final [B,1024,6]
duration [B]
success [B]
terminal_error_m [B]
environment_clearance_m [B]
self_clearance_m [B]
velocity/acceleration/Jerk metrics
```

**目的**

形成可执行轨迹及可审计失败原因，禁止只根据 TCP 到达判定成功。

### Step I10：50 Hz执行

**输入**

```text
q_final [B,1024,6]
duration [B]
```

**处理与输出**

在 `[0,duration]` 上对1024点轨迹做 periodic-aware 时间插值，每 `0.02 s` 输出一次六关节位置目标：

```text
q_target_control [B,N_control,6]
```

**目的**

将路径表示密度与控制频率解耦。1024是路径点数，不表示1024 Hz控制频率。

### Step I11：PhysX离线验证

**输入**

```text
q_final [N,1,1024,6]
duration [N,1]
active_side [N]
H1 balance checkpoint
```

H1平衡策略使用独立95维本体 observation，输出19维 H1 joint action。该状态不反馈给轨迹生成模型。

**输出**

```text
physx_success
active_arm_contact_events
max_base_tilt_rad
min_base_height_m
max_base_xy_drift_m
final_joint_tracking_error_rad
```

**目的**

验证几何安全轨迹在驱动、接触、重力和 H1 平衡耦合下是否仍可执行。PhysX不进入在线Visual CFM推理。

## 8. 研究结论边界

1. 环境避障依赖五相机视觉点云，但训练阶段使用 privileged obstacle tokens 作为 teacher 和碰撞损失标签；
2. 自碰撞依赖辅助臂自身关节角、FK和capsule模型，不是只靠图像判断；
3. 目标位置由外部任务系统给定，当前没有完成视觉目标检测与目标位姿估计；
4. 当前2帧视觉数据是静态图像复制，尚未验证动态障碍物速度估计；
5. capsule clearance 是工程近似，不能替代硬件碰撞检测和 emergency stop；
6. velocity、acceleration、Jerk limits 是仿真 planning soft limits，尚未经过真实机械臂标定；
7. 206条综合测试、512条PPO测试和26条PhysX子集使用不同任务与判据，成功率不能直接相乘；
8. 当前论文可使用的有效主线是 Visual CFM、多候选视觉筛选、安全终态投影、未截断时间缩放、exact safety gate 与 PhysX离线验证；PPO在专门碰撞集上有120/512修复，但集成接受数仍为0，不能宣称其提高最终206条性能。

## 9. 时间尺度、复现与实验协议

### 9.1 时间尺度

| 环节 | 时间定义 |
|---|---|
| Visual CFM flow time | 无量纲 `t in [0,1]` |
| Visual CFM推理 | 32个 Heun ODE steps |
| Visual CFM轨迹 | 64个生成点；Duration Head原始输出为 `0.8-5.0 s`且已冻结 |
| Step I4时间缩放 | 先插值为1024点，再计算未截断duration；30 s为有效性上限 |
| PPO refinement | 8个策略step，不对应物理控制周期 |
| PPO输出 | 1024个路径点 |
| Step I6/I7后处理 | 每次路径几何变化后均强制重算1024点时间缩放 |
| 动力学审计 | 1024点时间网格，判定相对容差 `1e-6` |
| PhysX simulation dt | `0.005 s`，200 Hz |
| 控制与渲染dt | `0.020 s`，50 Hz |

### 9.2 随机种子与确定性设置

| 阶段 | Seed |
|---|---:|
| Visual CFM v5配置 | `20260801` |
| 64候选固定评估 | `20260803` |
| 完整1024点集成评估 | `20260804` |
| full64 PPO v3训练与512条评估 | `20260809` |

训练与评估显式锁定 NumPy、PyTorch 和 CUDA seed；确定性评估关闭随机传感器扰动并使用固定checkpoint、固定任务ID和固定候选生成seed。PPO训练使用随机策略采样，复现时必须同时保持数据split、CUDA版本和配置文件不变。

### 9.3 固定评估协议

| 协议 | 样本 | 验证性质 |
|---|---:|---|
| 五相机完整集成测试 | 206 | TCP、视觉环境、自碰撞、动力学、duration联合成功 |
| PPO中段碰撞测试 | 512 | 首尾安全条件下的中段自碰撞修复与低冲击联合成功 |

### 9.4 已有对照与消融组定位

| 实验组 | 对比目的 | 与当前最终方法的关系 |
|---|---|---|
| `K=1` 与 `K=64` | 验证多候选生成和复筛作用 | 当前方法采用 `K=64` |
| privileged obstacle CFM 与 Visual CFM | 验证结构化真值环境表示替换为视觉表示后的性能变化 | privileged仅作teacher/训练监督 |
| 单腕相机与五相机 | 验证视角数量和固定相机补盲作用 | 当前方法采用五相机 |
| no-Jerk | 验证 Jerk loss 对机械冲击指标的作用 | 当前Visual CFM包含Jerk loss |

这些对照实验使用各自固定数据和判据。旧实验结果不能与206条最终集成成功率直接拼接，也不能把 PPO 接受数为0的结果写成最终方法性能增益。
