# 基于条件流匹配与物理验证的航天员外肢体机器人多候选轨迹生成方法：思路与实验组梳理

生成日期：2026-07-30  
工程范围：`D:\work_space\isaacsim_lab_zbot_6s`  
研究对象：原六自由度外肢体机械臂轨迹生成系统，不包含人形机器人平衡与旧版单臂抓取部署实验。

## 1. 先给出准确结论

本文方法不是强化学习策略，而是一个**监督式 Conditional Flow Matching（CFM）轨迹生成器与约束/物理验证后端组成的分层系统**。它解决的是：给定当前六关节状态、目标 TCP 位置和障碍观测，一次生成多条完整关节轨迹，再通过运动学、平滑性和物理碰撞检查选择可执行轨迹。

现有证据支持以下结论：

1. 不感知障碍的 Direct Minimum-Jerk 在随机静态、动态和太空碎石混合场景中只有 `1%` 安全到达率，说明问题不能靠起终点平滑插值解决。
2. 碰撞感知微调将 privileged-token 系统成功率从 `67%` 提升到 `78%`，候选碰撞率从 `25.56%` 降到 `15.22%`，是安全性能提升最明确的学习模块。
3. 多候选数量从 `K=1` 增至 `K=64` 时，组件协议下成功率从 `38%` 提升到 `90%`，证明生成分布中确实存在可供选择的多条轨迹模式，但计算量近似随 K 增长。
4. Terminal IK、PhysX 多候选复筛和 spline smoothing 分别负责终点精度、物理碰撞拒绝和低冲击可执行性，不能只用网络验证损失代替这些模块。
5. 修正视觉评测分支后，单腕部 Visual CFM 在不使用真值几何选路和 PhysX 碰撞后改选时成功率为 `41%`。
6. 用 front/side/top 三台固定相机重建障碍 AABB 来选择腕部 Visual CFM 候选时成功率为 `50%`，相对 41% 提升 9 个百分点，但 exact McNemar `p=0.1496`，尚未达到统计显著。
7. 单腕 Visual CFM 加入**仿真真值障碍几何排序与 PhysX 多候选复筛**后达到 `78%`。这组是仿真系统性能上限，不是纯视觉或可直接实机部署的结果。
8. 四相机 channel-concat early fusion 没有优于单腕相机：direct-vision 为 `27% vs 41%`，完整 privileged 后端为 `74% vs 78%`。增加相机数量本身并不等于更有效地使用视觉信息。
9. 低冲击损失主要改善轨迹品质而非安全到达率。去掉速度/加速度/jerk 正则后成功率略升到 `81%`，但运动代价增加 `87.33%`、峰值 jerk 增加 `18.17%`。

> **证据审计提醒：** 旧版评测器在图像平移为 0 时会误走 privileged obstacle-token 分支。因此旧 `K/G/后处理/409-task` 日志只能用于规划组件分析，不能再引用为视觉性能。修正后的视觉主结果是 `41%/50%/78%` 三组 100-task 结果。

## 2. 方法总体思路

### 2.1 任务定义

机械臂有 6 个可动 Revolute Joint。USD 中的 FixedJoint 是装配约束，不属于模型输出，也不参与控制。当前研究只规划 TCP 位置，不规划末端姿态。

- 起点关节：`q_start ∈ R^6`。
- 目标：`p_goal ∈ R^3`，由随机目标关节 `q_goal` 做正运动学得到。
- 任务条件：`c_task = [q_start, p_goal] ∈ R^9`。
- `q_goal`：只用于专家轨迹生成和离线评价，不输入 CFM。
- 关节采样：起点和目标分别独立均匀采样于 `[-π, π]^6`。
- 障碍：每个任务同时包含静态障碍、动态障碍和太空碎石。
- 仿真步长：`1/120 s`。
- 轨迹/障碍同步验证频率：`50 Hz`。
- 视觉两帧间隔：`0.10 s`。

### 2.2 模型真正的输入与输出

| 接口 | 内容 | 张量形状 |
|---|---|---:|
| 共同任务条件 | 当前关节角 `q_start` + 目标 TCP 位置 `p_goal` | `[B,9]` |
| Privileged 障碍输入 | 最多 5 个障碍的类型、尺寸、位置、四元数、线速度及 mask | `[B,5,14]` + `[B,5]` |
| 单腕视觉输入 | 两帧 RGB、depth、semantic，每帧 5 通道 | `[B,2,128,128,5]` |
| 四相机视觉输入 | wrist/front/side/top，每台两帧 5 通道 | `[B,4,2,128,128,5]` |
| CFM 训练期内部输入 | 加噪轨迹状态 `x_t`、流时间 `t`、任务条件、障碍/视觉 latent | `x_t:[B,64,6]` + 其他条件 |
| CFM 训练期直接输出 | 条件向量场 `v_theta(x_t,t,c)` 和 duration 预测 | `[B,64,6]` + `[B,1]` |
| 推理期系统输出 | Heun ODE 积分后的完整关节位置轨迹和持续时间 | `q:[B,64,6]` + `duration:[B,1]` |

`64×6` 中，64 是轨迹采样点数，6 是六个可动关节的角度，不是 6 类状态。推理使用 32 步 Heun ODE；32 是求解 Flow ODE 的数值积分次数，不是输出轨迹点数。

### 2.3 模型与训练链路

1. 通过 PhysX、运动学和轨迹优化生成 4096 条可行专家轨迹。
2. 用 `q_start + p_goal + obstacle tokens` 训练 privileged obstacle CFM。
3. 加入 collision-clearance loss，对 privileged CFM 做碰撞感知微调。
4. 采集腕部或四相机 RGB-D-semantic。
5. 用 latent distillation 让视觉编码器拟合 privileged obstacle encoder 的 128 维 latent。
6. 将视觉 latent、任务条件和 CFM 联合微调，得到 Visual CFM。
7. 推理时从独立高斯噪声采样 K 条轨迹，经 Terminal IK、样条、时标化、候选排序和 PhysX 验证输出一条轨迹。

| 训练阶段 | 主要输入 | 监督目标/输出 | Epoch | 最佳验证指标 |
|---|---|---|---:|---:|
| 专家数据生成 | `q_start`、`q_goal`、障碍真值、PhysX | `q_expert[64,6]`、duration | - | 4096 条可行样本 |
| Base obstacle CFM | `x_t,t,q_start,p_goal,obstacle tokens` | flow、起点、TCP、duration、平滑项 | 5000 | loss `0.9155` |
| Collision-aware fine-tuning | 与 Base CFM 相同 | 增加 collision-clearance loss | 300 | loss `1.0249` |
| 单腕 latent distillation | 两帧腕部 RGB-D-semantic | privileged latent `[B,128]` | 40 | MSE `0.006930` |
| 单腕 Visual CFM fine-tuning | `x_t,t,q_start,p_goal,wrist images` | flow + duration + 几何/平滑损失 | 30 | loss `1.030464` |
| 四相机 latent/CFM 训练 | 四路两帧图像，其他相同 | 同上 | 40 + 30 | MSE `0.004116`；loss `1.011839` |
| No-jerk 消融 | privileged 输入 | 去掉 jerk loss | 120 | loss `0.9395` |
| No-smooth 消融 | privileged 输入 | 去掉 velocity/acceleration/jerk loss | 120 | loss `0.8447` |

训练数据划分为 Train/Validation/Test=`3277/410/409`。基础优化器为 AdamW，学习率 `1e-4`，weight decay `1e-4`，bf16 mixed precision，梯度裁剪 `1.0`；主训练 seed 为 `20260724`。

### 2.4 损失函数

总损失为：

```text
L = 1.0 L_flow
  + 10.0 L_start
  + 5.0 L_tcp
  + 0.1 L_velocity
  + 0.1 L_acceleration
  + 0.05 L_jerk
  + 1.0 L_duration
  + 2.0 L_collision
```

该方法没有 RL Reward。这里的 `L_collision` 是可微几何近似，PhysX 是执行前的硬验证；二者作用不同。

### 2.5 多候选与物理验证

默认设置为 `K=32`，每个候选依次执行：

1. 6 次重启的 position-only Terminal IK。
2. 12 个控制点的 cubic spline smoothing。
3. 按速度、加速度和 jerk 约束调整 duration。
4. 按末端误差、运动代价和 predicted clearance 排序。
5. 最多将 8 条候选送入 PhysX，选择第一条无碰撞轨迹。
6. 执行期间检测未预测接触并触发 emergency stop。

成功要求同时满足 TCP 误差不超过 `0.01 m`、duration 不超过 `5 s`、运动学约束满足、自碰撞和环境碰撞均未发生。因此本文成功率是**无碰撞安全到达率**。

## 3. “最终实验组”必须分成两种口径

### 3.1 仿真性能上限组 FG-P

**Corrected Wrist Visual CFM + privileged geometry ranking + multi-candidate PhysX screening**

- 生成器输入：`q_start[6] + p_goal[3] + wrist[2,128,128,5]`。
- 候选选择额外输入：仿真真值障碍几何；PhysX 可在最多 8 个候选之间改选。
- 候选数/引导：`K=32, G=0`。
- 输出：最终被选中的 `q[64,6] + duration`。
- 100-task 成功率：`78%`，Wilson 95% CI `[68.93%,85.00%]`。
- 候选 PhysX 碰撞率：`26.42%`。
- 平均 clearance：`0.0700 m`。
- 平均运动代价：`9.7322`。
- 平均峰值 jerk：`15.7014 rad/s^3`。

该组用于回答“视觉生成先验与理想物理安全后端组合后，仿真系统能达到什么水平”。它不是纯视觉，也不能直接迁移到真实环境，因为候选排序和复筛使用了仿真真值。

### 3.2 部署桥接组 FG-C

**Wrist Visual CFM + fixed front/side/top camera geometry reconstruction**

- 轨迹生成输入：与 FG-P 相同，只读取腕部两帧 RGB-D-semantic。
- 安全层输入：三台固定相机各两帧 depth-semantic。
- 候选选择：深度反投影、点云聚类、AABB 拟合、两帧 Hungarian matching 与恒速估计。
- 禁止读取障碍位姿/尺寸/速度真值。
- PhysX 每个任务只评价最终首选轨迹一次，不允许碰撞后重选。
- 输出：最终首选 `q[64,6] + duration`。
- 100-task 成功率：`50%`，Wilson 95% CI `[40.38%,59.62%]`。
- 相对 wrist direct：`+9 pp`，McNemar `p=0.1496`，未达到统计显著。

该组更接近真实部署的信息边界，但 semantic mask 仍来自 Isaac Sim 真值，尚未形成真正的实机闭环方案。

下表的“相对 FG-P”以 78% 仿真性能上限组为参照。不同协议之间的差值用于系统角色分析；只有后文标明的同输入、同后端实验才属于严格单变量消融。

| 组别 | 轨迹生成输入 | 候选选择/物理信息 | 输出 | 成功率 | 相对 FG-P | 主要比较目的 |

| Direct Minimum-Jerk | `q_start,p_goal`，无障碍观测 | 无候选筛选 | `q[64,6]+duration` | 1% | -77 pp | 证明混合障碍任务不能靠直接平滑插值解决 |

| Collision-aware CFM + shield | 与 Base CFM 相同 | 与 Base CFM 相同 | 同上 | 78% | 0 pp | 证明长期碰撞感知训练比仅靠基础生成更安全 |

| FG-P：Wrist Visual + Privileged Backend | 腕部视觉生成 | 真值几何排序 + PhysX 多候选复筛 | 同上 | 78% | 0 pp | 仿真完整系统性能上限 |

主结果说明：

- Direct 到 FG-P 的 `+77 pp` 不能全部归因于 CFM 网络，因为 FG-P 同时包含视觉生成、Terminal IK、样条、真值 clearance 排序和 PhysX 复筛。
- Base CFM 67% 到 Collision-aware CFM 78% 是较严格的训练消融，支持 collision-aware fine-tuning。
- Wrist direct 41% 到 FG-P 78% 的 `+37 pp` 主要体现 privileged 候选选择和 PhysX 复筛的作用，不是视觉编码器自身提升。
- Wrist direct 41% 到 fixed-3 50% 使用相同生成器和最终一次 PhysX 评价，较直接地检验固定相机几何层；但当前样本量下提升不显著。

## 5. 各项对比实验与消融实验

### 5.1 碰撞感知微调消融

两组输入、输出、K、G 和物理后端相同，只改变是否做 collision-aware fine-tuning。

| 设置 | 输入 | 输出 | 成功率 | 候选碰撞率 | 运动代价 | 峰值 jerk |
|---|---|---|---:|---:|---:|---:|
| Base CFM | task condition + privileged tokens | `q[64,6]+duration` | 67% | 25.56% | 8.3748 | 19.0947 |
| Collision-aware CFM | 相同 | 相同 | 78% | 15.22% | 7.9188 | 16.9366 |

配对 McNemar `p=0.0266`。该实验说明 collision-clearance loss 不只是降低训练损失，还能显著提高物理安全到达率，并同时降低候选碰撞和冲击代理。

### 5.2 多候选数量 K 消融

所有组使用相同 token-conditioned 生成输入、Terminal IK、样条、G=12 和 PhysX 后端，只改变候选数量。由于旧视觉分支缺陷，该表是**规划组件证据，不是视觉证据**。

| K | 输入/输出变化 | 成功率 | 候选碰撞率 | 平均耗时/任务 |
|---:|---|---:|---:|---:|
| 1 | 输入不变；生成 1×`[64,6]`，最终仍输出一条 | 38% | 7.32% | 3.86 s |
| 4 | 生成 4 条候选 | 53% | 24.29% | 6.79 s |
| 8 | 生成 8 条候选 | 63% | 18.18% | 10.55 s |
| 16 | 生成 16 条候选 | 72% | 13.25% | 18.00 s |
| 32 | 生成 32 条候选 | 80% | 19.19% | 31.97 s |
| 64 | 生成 64 条候选 | 90% | 15.09% | 63.67 s |

K=1 与 K=64 的 McNemar `p=4.44×10^-16`。该实验明确证实多候选是主要性能来源；`K=32` 是性能与计算量的折中，`K=64` 更适合离线上限而非实时部署。

### 5.3 在线安全引导步数 G 消融

输入、输出和 `K=32` 不变，只改变对候选轨迹执行可微 safety loss 梯度修正的次数。该表同样属于旧 token-conditioned 组件证据。

| G | 成功率 | 平均 clearance | 运动代价 |
|---:|---:|---:|---:|
| 0 | 82% | 0.0693 m | 9.1198 |
| 4 | 79% | 0.0726 m | 8.8211 |
| 8 | 78% | 0.0721 m | 9.0380 |
| 12 | 80% | 0.0712 m | 9.0409 |
| 20 | 79% | 0.0715 m | 8.5796 |

G=0 与 G=12 的 McNemar `p=0.6875`，没有成功率显著提升。历史日志显示可微 safety loss 可下降约 96%～98%，但 PhysX 成功率没有同步提高。因此在线安全引导只被证实为“优化几何近似目标”，不能称为物理安全证明。

### 5.4 Terminal IK、PhysX 复筛和样条消融

这些组保持生成输入和输出接口不变，只关闭一个后处理模块。证据来自旧 token-conditioned 组件协议。

| 设置 | 成功率 | 运动代价 | 峰值加速度 | 峰值 jerk | 说明 |
|---|---:|---:|---:|---:|---|
| Full component stack | 80% | 9.0409 | 3.6504 | 17.0684 | 组件参考组 |
| No Terminal IK | 0% | - | - | - | 当前 CFM 不能独立保证 1 cm 终点约束 |
| No multi-candidate PhysX screening | 73% | 8.8167 | 3.7962 | 17.8931 | 物理复筛贡献约 7 pp |
| No spline smoothing | 97% | 166.9531 | 543.5634 | 3849.9392 | 几何成功率高，但轨迹不可作为低冲击输出 |

该消融说明：Terminal IK 是硬终点约束投影；PhysX 负责拒绝近似几何遗漏；样条与时标化负责把几何可达路径变成可执行轨迹。No-spline 的 97% 不能解释为优于完整系统。

### 5.5 低冲击损失消融

三组均使用 privileged 输入和相同 K32/G12 后端，只改变训练损失。输出始终是 `q[64,6]+duration`。

| 训练损失设置 | 成功率 | 运动代价 | 峰值加速度 | 峰值 jerk |
|---|---:|---:|---:|---:|
| Full velocity/acceleration/jerk loss | 78% | 7.9188 | 3.5103 | 16.9366 |
| No jerk loss | 80% | 10.6168 | 3.5376 | 18.2444 |
| No velocity/acceleration/jerk loss | 81% | 14.8324 | 4.0930 | 20.0126 |

去掉 jerk loss 后运动代价增加 `34.07%`、峰值 jerk 增加 `7.72%`；去掉全部平滑正则后运动代价增加 `87.33%`、峰值 jerk 增加 `18.17%`。这证实低冲击损失降低了运动学冲击代理，但没有证实真实电能、关节力矩、结构应力或机械磨损下降。

### 5.6 单腕与四相机消融

两组从同一个 privileged checkpoint 初始化，使用相同数据划分、40 轮 latent distillation、30 轮 Visual CFM 微调、seed=42；唯一有意差异是视觉输入从 10 通道变成 40 通道 early fusion。

| 协议 | 单腕输入/结果 | 四相机输入/结果 | 差值 | McNemar p |
|---|---|---|---:|---:|
| Direct-vision | `[2,128,128,5]`，41% | `[4,2,128,128,5]`，27% | -14 pp | 0.00661 |
| Privileged full backend | 同上，78% | 同上，74% | -4 pp | 0.3438 |

四相机 latent MSE 比单腕低 `40.61%`，但 direct-vision 成功率显著下降，采样时间增加约 `130%`。该实验说明 teacher-latent 拟合更好不等于候选轨迹更安全，也说明简单 channel concatenation 不能有效利用多视角几何。

### 5.7 三固定相机几何安全层对比

| 方法 | 生成输入 | 候选排序信息 | PhysX 角色 | 成功率 | Wilson 95% CI |
|---|---|---|---|---:|---:|
| Wrist direct | 腕部两帧 RGB-D-semantic | 无障碍几何排序 | 最终首选评价一次 | 41% | `[31.87%,50.80%]` |
| Wrist + fixed-3 | 腕部生成；固定三相机重建 | 重建 AABB 和速度 | 最终首选评价一次 | 50% | `[40.38%,59.62%]` |
| Wrist + privileged backend | 腕部生成 | 障碍几何真值 | 最多 8 候选复筛 | 78% | `[68.93%,85.00%]` |

固定相机重建 recall=`88.06%`、precision=`100%`、平均中心误差=`7.82 mm`、平均 AABB IoU=`0.218`。Fixed-3 相对 direct 的 `+9 pp` 未显著；相对 privileged 的 `-28 pp` 显著（`p=7.45×10^-9`）。结果支持固定相机显式几何是可行方向，但当前 AABB 尺寸、动态预测和 semantic 真值依赖仍限制性能。

### 5.8 修正后的视觉扰动实验

每个任务只生成一次受扰视觉观测，32 个候选共享该观测；视觉扰动与 CFM 候选使用独立随机数生成器。

| 扰动 | Visual direct | 相对 clean 41% | Privileged full backend | 相对 clean 78% |
|---|---:|---:|---:|---:|
| Clean | 41% | 0 pp | 78% | 0 pp |
| RGB 高斯噪声，σ=12.75 灰度级 | 36% | -5 pp | 78% | 0 pp |
| 深度高斯噪声，σ=0.02 m | 32% | -9 pp | 78% | 0 pp |
| 深度/语义随机丢弃 10% | 38% | -3 pp | 79% | +1 pp |
| 图像随机平移 ±4 px | 32% | -9 pp | 78% | 0 pp |
| 腕部相机完全遮蔽 | 38% | -3 pp | 80% | +2 pp |

图像平移的原始 McNemar `p=0.0352`，Holm 校正后为 `0.1758`。该实验只支持“中等扰动下未观察到大幅崩溃”，不能证明强鲁棒或统计等价。完全遮蔽只下降 3 pp 反而说明视觉生成器仍较多依赖 `q_start`、目标位置和任务分布先验；完整后端稳定在 78%～80% 主要体现 privileged 几何与 PhysX 的容错能力，不是视觉编码器鲁棒性。

### 5.9 规模与随机性审计

- 旧 token-conditioned 完整 test split：409 个 mixed-all 任务，成功率 `80.44%`、运动代价 `9.0804`、峰值 jerk `16.6864`。它能支持规划组件的规模稳定性，不能作为 409-task 视觉结果。
- 三个候选采样 seed 的 100-task 成功率为 `80%/78%/83%`，均值 `80.33% ± 2.05%`。这些是候选采样 seed，不是三个独立训练 seed。
- 修正后的真实视觉主实验目前是 100 tasks，尚未完成 409-task 修正重跑。

| Expert vs Direct | 任务可解；直接插值不具备混合障碍避障能力 | 不能量化学习模型贡献 |

| No spline | 平滑/时标化对低冲击执行必要 | 不能把 97% 几何成功率当作可执行性能 |

| 视觉扰动 | 量化了当前模型在五类中等扰动下的变化范围 | 不能证明严格鲁棒性、非劣效或外参误差适应性 |

## 7. 最准确的论文叙事

建议将本文方法表述为：

> 一种面向航天员外肢体机器人的视觉引导多候选轨迹生成与物理验证方法。Conditional Flow Matching 学习随机混合障碍任务中的多模态关节轨迹先验；碰撞感知训练降低候选碰撞；Terminal IK、样条时标化和 PhysX 复筛分别保障末端精度、低冲击品质和仿真物理安全。修正后的腕部视觉生成器直接安全到达率为 41%，三固定相机几何安全层达到 50%，结合仿真真值几何与多候选 PhysX 后端时达到 78%。

不建议写成：

- “本文实现了 78% 的纯视觉避障成功率”；
- “PhysX safety shield 可以直接部署到 real-world”；
- “四相机没有作用”；
- “安全引导显著提高成功率”；
- “模型不依赖 Terminal IK”；
- “低冲击损失已经证明节能或减少机械磨损”；
- “409-task 80.44% 是修正后的视觉结果”。
